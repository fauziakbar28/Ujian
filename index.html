👤 Identitas Guru

📧 EmailJS (Untuk kirim hasil ke email)

Cara setup EmailJS:
1. Daftar di emailjs.com (gratis 200 email/bulan)
2. Buat Email Service (hubungkan Gmail/Outlook)
3. Buat Email Template dengan variabel: {{to_email}}, {{student_name}}, {{student_nis}}, {{student_class}}, {{quiz_title}}, {{score}}, {{passed}}, {{details}}, {{submitted_at}}
4. Salin Public Key, Service ID, dan Template ID ke bawah ini

🤖 Gemini AI API Key (Untuk auto-generate soal)

Cara mendapatkan API Key:
1. Buka aistudio.google.com/apikey
2. Login dengan akun Google → Klik "Create API Key"
3. Salin dan tempel di bawah ini (gratis)
